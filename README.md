Panel visual con los ejercicios de HTML, CSS y JavaScript realizados durante mi formación en Desarrollo de Aplicaciones Web (Certificado de Profesionalidad + Bootcamp Full Stack, Coderhouse 2025).

🔗 **Demo en vivo:** _(añade aquí la URL de Vercel una vez desplegado)_

## Contenido

- **HTML & CSS** (16 ejercicios): etiquetado semántico, listas y enlaces, imágenes, tablas, formularios, iframes, multimedia (audio/vídeo HTML5), box model, layouts, flexbox, diseño responsive (RWD).
- **JavaScript** (16 ejercicios): reloj en tiempo real, date picker, countdown, galerías de imágenes, lightbox, sliders, tabs, tómbola interactiva, editor de texto, calculadora, mensajería simulada, Ajax & XML, jQuery.

Cada sección tiene su propia página de índice con acceso directo a cada ejercicio.

## Tecnologías

- HTML5 semántico
- CSS3 (Flexbox, diseño responsive)
- JavaScript vanilla
- jQuery / jQuery UI (vía CDN)
- GLightbox (vía CDN)

Proyecto 100% estático — sin backend ni base de datos, pensado para desplegarse directamente en Vercel o GitHub Pages.

## Estructura del proyecto

```
panel-daw/
├── index.html          # Landing con acceso a ambas secciones
├── favicon.ico
├── html-css/
│   ├── index.html       # Galería de ejercicios HTML/CSS
│   └── ...
└── javascript/
    ├── index.html       # Galería de ejercicios JavaScript
    └── ...
```

## Despliegue local

No requiere build ni dependencias. Basta con abrir `index.html` en el navegador, o servirlo con cualquier servidor estático:

```bash
npx serve .
```
